📖 Subset de Python Soportado (Extraído de code.py)

El intérprete paso a paso ejecuta en el navegador el subset específico de Python empleado en los algoritmos de code.py:

1. Sentencias y Control de Flujo

  • Funciones y recursión: def fn(a, b=0): y return x, y
  • Clases y nodos enlazados: class Node: con def __init__(self, key):
  • Condicionales: if, elif, else (multilínea o en una línea)
  • Bucles: for x in ...: (con desempaquetado for u, v, w in edges:) y while cond:
  • Control: break, continue, pass, global calls
  • Excepciones: raise ValueError("mensaje")
  • Múltiples sentencias en una línea separadas por ;

2. Asignaciones y Operadores

  • Intercambio y desempaquetado: a[i], a[m] = a[m], a[i], i, j, k = lo, mid+1, lo
  • Asignación aumentada: +=, -=, *=, //=, %=
  • Aritmética: +, -, *, /, división entera //, módulo %, **
  • Comparación (incluye orden lexicográfico de tuplas): <, <=, >, >=, ==, !=
  • Identidad y pertenencia: is None, is not None, in, not in
  • Lógicos: and, or, not

3. Estructuras de Datos y Comprehensions

  • Listas: [1, 2, 3], repetición [0] * 10, concatenación a + b, slicing a[lo:hi+1]
  • Métodos de list: .append(x), .pop(), .extend(iter)
  • Tuplas: (0, start), (u, v, w)
  • Diccionarios: {"A": [("B", 4)]}, .items(), .keys(), .values()
  • Dict & List Comprehensions: {v: float("inf") for v in vertices}
  • Conjuntos (set): visited = {start}, set(), .add(x)

4. Módulos y Funciones Built-in

  • from collections import deque: deque(), .append(x), .popleft()
  • import heapq: heapq.heappush(pq, item), heapq.heappop(pq)
  • Built-ins: len(), range(start, stop, step), min(), max(), sorted(), sum(), abs()
  • Conversión y formato: list(), set(), float("inf"), int(), str(), " -> ".join(...)
  • Salida e interpolación: print(...) y f"push {value} -> {stack}"
